# ULON Extractor (Figma Plugin)

Плагин для Figma, который быстро извлекает палитру цветов и растровые изображения из макетов или выделенных слоев и формирует оптимизированный JSON для интеграции с проектами ULON.

## Возможности

- **Извлечение цветов**: сканирует все заливки (`fills`), обводки (`strokes`), фоны (`backgrounds`), тени (`effects`) и текстовые стили, формируя чистый массив цветов в формате HEX + исходный CSS RGB/RGBA.
- **Оптимизированный экспорт изображений**: автоматически находит растровые картинки, дедуплицирует их по `imageHash` и экспортирует оптимизированные web-версии (JPG 600px).
- **Тексты и типографика**: собирает параметры шрифтов, начертаний, размеров, межстрочных и межбуквенных интервалов, выравниваний и цветов.
- **Структура секций**: секции сохраняются на верхнем уровне структуры, а внутри каждой секции устранена промежуточная вложенность контейнеров — выводятся плоские списки текстовых блоков секции.
- **SVG и векторная графика**: автоматическое распознавание и экспорт иконок в SVG.
- **Шрифты**: отдельный сводный реестр всех задействованных шрифтовых гарнитур и их начертаний.

## Формат выходного JSON

```json
[
  { "colors": [ { "hex": "#111827", "original": "rgb(17, 24, 39)" } ] },
  { "images": [ { "id": "1:23", "name": "logo", "imageHash": "...", "data": "data:image/jpeg;base64,..." } ] },
  { "texts": [ { "id": "1:15", "tag": "p", "text": "...", "className": "font-inter-700-48", "section": "Hero" } ] },
  {
    "structure": [
      {
        "id": "1:2",
        "name": "Hero",
        "tag": "div",
        "className": "section-hero",
        "backgroundColor": "#ffffff",
        "children": [
          {
            "id": "1:15",
            "name": "Title",
            "tag": "p",
            "text": "Hello World",
            "fontFamily": "Inter",
            "fontSize": 48,
            "fontWeight": 700,
            "lineHeight": 56,
            "letterSpacing": 0,
            "textAlign": "left",
            "color": "#111827",
            "backgroundColor": null,
            "className": "font-inter-700-48"
          }
        ]
      }
    ]
  },
  { "svgs": [ { "id": "1:30", "name": "icon-arrow", "content": "<svg ...>...</svg>" } ] },
  { "fonts": [ { "family": "Inter", "weights": [400, 700] } ] }
]
```

## Сборка и разработка

```bash
# Установка зависимостей
npm install

# Сборка плагина
npm run build

# Разработка в режиме watch
npm run dev
```

## Установка в Figma

1. В Figma откройте меню: **Plugins** → **Development** → **Import plugin from manifest...**
2. Выберите файл `manifest.json` в корне этого репозитория.
