# ULON Extractor (Figma Plugin)

Плагин для Figma, который быстро извлекает палитру цветов и растровые изображения из макетов или выделенных слоев и формирует оптимизированный JSON для интеграции с проектами ULON.

## Возможности

- **Извлечение цветов**: сканирует все заливки (`fills`), обводки (`strokes`), фоны (`backgrounds`), тени (`effects`) и текстовые стили, формируя чистый массив цветов в формате HEX + исходный CSS RGB/RGBA.
- **Оптимизированный экспорт изображений**: автоматически находит растровые картинки, дедуплицирует их по `imageHash` и экспортирует оптимизированные web-версии (JPG 600px).
- **Компактный и быстрый**: результат упаковывается в ультра-легкий JSON (~50–200 КБ), который мгновенно копируется в буфер обмена.

## Формат выходного JSON

```json
[
  {
    "colors": [
      { "hex": "#000000B2", "original": "rgba(0, 0, 0, 0.700)" },
      { "hex": "#D183401A", "original": "rgba(209, 131, 64, 0.100)" }
    ]
  },
  {
    "images": [
      {
        "id": "1:23",
        "name": "logo_3",
        "imageHash": "a1b2c3d4...",
        "width": 200,
        "height": 60,
        "scaleMode": "FILL",
        "data": "data:image/jpeg;base64,..."
      }
    ]
  }
]
```

## Сборка и разработка

```bash
# Установка зависимостей
npm install

# Сборка плагина
npm run build

# Разработка в режиме watch
npm run dev
```

## Установка в Figma

1. В Figma откройте меню: **Plugins** → **Development** → **Import plugin from manifest...**
2. Выберите файл `manifest.json` в корне этого репозитория.
